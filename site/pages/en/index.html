Questions

Is Skill Stow free?

Yes. Skill Stow is free and open source under the MIT license, with no account and no paid tiers.

Which agents are supported?

Skill Stow scans skill folders for {{len .Agents}} agents, including Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode, Windsurf, Cline, Kiro, Trae and Qwen Code, plus custom folders added in Settings. Per-skill switches work for the {{len .Native}} agents whose own config supports it: {{range $i, $a := .Native}}{{if $i}}{{if last $i (len $.Native)}} and {{else}}, {{end}}{{end}}{{$a.Name}}{{end}}.

How is it different from npx skills?

npx skills installs skills from the command line. Skill Stow shows everything installed across agents and projects, groups skills installed with npx skills into collections, and adds per-agent switches, offline security checks, updates with a diff, and cleanup. The two work side by side.

When does it change files on my Mac?

Only when you act. Turning a skill off edits only the skill entries in that agent's config file. Adding, updating, deleting and Tidy Up change your skill folders, and anything removed goes to the Trash.

macOS says it can't open Skill Stow. What do I do?

The app isn't signed with an Apple Developer ID yet, so macOS asks once on first launch. On macOS 15 or later, open the app once, then click Open Anyway in System Settings › Privacy & Security. On macOS 12 to 14, Control-click the app in Applications and choose Open. Later updates install from Skill Stow › Check for App Updates…, or you can build it from source.

Is there a Windows or Linux version?

No. Skill Stow is a native macOS app for macOS 12 or later, on Apple Silicon and Intel.
