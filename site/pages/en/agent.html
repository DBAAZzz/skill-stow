Frequently asked questions

Where does {{$a.Name}} store skills?

Global skills are stored in {{home $a.Skills}}{{if $a.Project}}, and project-scoped skills live in {{range $i, $f := $a.Project}}{{if $i}} or {{end}}{{$f.Path}}{{end}} inside the repository{{end}}. Each skill is a folder containing a SKILL.md file.

Does {{$a.Name}} read ~/.agents/skills?

{{if $a.ReadsShared}}Yes. {{$a.Name}} scans the shared ~/.agents/skills directory globally, so skills placed there are available to it.{{else}}Not globally. {{$a.Name}} only scans its own global folder, {{home $a.Skills}}.{{if $a.ProjectShared}} Within projects, however, it does read .agents/skills.{{end}}{{end}}

Can I disable a single skill in {{$a.Name}}?

{{if $a.Native}}Yes, by adding an entry to {{$a.Native.File}}. Skill Stow updates this config automatically when you toggle the switch.{{else}}Not via configuration. Every skill in its scanned folders is always on, so remove the skill from those directories to prevent {{$a.Name}} from loading it.{{end}}
