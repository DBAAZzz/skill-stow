常见问题

Skill Stow 是否收费？

完全免费。Skill Stow 基于 MIT 协议开源，无需注册账号，也没有付费版本。

支持哪些 Agent？

支持读取 {{len .Agents}} 个 Agent 的 Skill 目录，包括 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot、OpenCode、Windsurf、Cline、Kiro、Trae、Qwen Code 和通义灵码，也可在「设置 › Agent 管理」中添加自定义目录。按 Skill 独立启停目前支持原生配置允许该操作的 {{len .Native}} 个 Agent：{{range $i, $a := .Native}}{{if $i}}、{{end}}{{$a.Name}}{{end}}。

与 npx skills 有什么区别？

npx skills 负责在命令行中安装 Skill。Skill Stow 则统一呈现所有 Agent 与项目中已安装的 Skill，自动识别由 npx skills 安装的集合，并提供按 Agent 启停、离线安全检查、差异对比更新与目录整理功能。两者可以配合使用。

会修改我 Mac 上的文件吗？

仅在你主动操作时才会写入。启停开关只修改对应 Agent 配置文件中与 Skill 相关的字段；导入、更新、删除与「整理」会变更 Skill 目录，所有被移除的文件默认移至废纸篓。

macOS 提示无法打开 Skill Stow，怎么办？

应用暂未使用 Apple 开发者 ID 签名，首次打开时 macOS 会要求确认一次。macOS 15 及以上：先打开一次应用，再到「系统设置 › 隐私与安全性」中点击「仍要打开」。macOS 12 至 14：在「应用程序」中按住 Control 点按应用，选择「打开」。之后的更新可在「Skill Stow › 检查应用更新…」中完成，也可以从源码构建。

是否提供 Windows 或 Linux 版本？

暂不提供。Skill Stow 是原生 macOS 应用，支持 macOS 12 及以上系统，兼容 Apple Silicon 与 Intel 芯片。
