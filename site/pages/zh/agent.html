常见问题

{{$a.Name}} 的 Skill 存放在哪个目录？

全局 Skill 位于 {{home $a.Skills}}{{if $a.Project}}，项目级 Skill 位于项目根目录下的 {{range $i, $f := $a.Project}}{{if $i}} 或 {{end}}{{$f.Path}}{{end}}{{end}}。每个 Skill 均为一个包含 SKILL.md 的文件夹。

{{$a.Name}} 会读取 ~/.agents/skills 吗？

{{if $a.ReadsShared}}会。{{$a.Name}} 会在全局扫描通用目录 ~/.agents/skills，安装在此处的 Skill 对它直接可见。{{else}}全局不会。{{$a.Name}} 仅扫描自身的全局目录 {{home $a.Skills}}。{{if $a.ProjectShared}}但在项目内，它会读取 .agents/skills。{{end}}{{end}}

能否在 {{$a.Name}} 中单独停用某个 Skill？

{{if $a.Native}}可以，在 {{$a.Native.File}} 中添加对应配置即可。在 Skill Stow 中切换开关时，应用会自动完成写入。{{else}}暂不支持通过配置停用。其扫描目录中的 Skill 均处于「始终启用」状态，如需停用请将 Skill 从对应目录移出。{{end}}

如何查看 Mac 上 {{$a.Name}} 的全部 Skill？

Skill Stow 会将 {{$a.Name}} 实际读取的全部 Skill（包括专属目录、共享目录与项目目录）汇总到看板视图的独立一列中。手动排查则需按上表逐个目录查看。
