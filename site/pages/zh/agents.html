大多数 AI 编程 Agent 会从主目录下的专属目录（例如 ~/.claude/skills 或 ~/.codex/skills）及各项目内的目录加载 Skill。不少 Agent 还会读取通用目录 ~/.agents/skills，放一份即可多端共用。目前仅 {{len .Native}} 个 Agent 支持通过原生配置文件单独停用某个 Skill：{{agentLinks .Native}}。

通用目录：~/.agents/skills

Agent Skills 采用统一结构——一个包含 SKILL.md 的目录，因此不同 Agent 可以共用同一路径。以下 Agent 会在全局读取 ~/.agents/skills：

{{agentLinks (sharedReaders .Agents)}}。

此外，部分 Agent 还会跨目录读取其他 Agent 的专属目录：

    {{- range crossReads .Agents}}
  • {{.Agent.Name}} 会读取 {{range $i, $d := .Dirs}}{{if $i}} 和 {{end}}{{home $d}}{{end}}
    • {{- end}}

因此，存放在某一位置的 Skill 可能会被比预期更多的 Agent 加载。Skill Stow 会为每个 Skill 准确标注所有实际读取它的 Agent。

支持按 Skill 独立启停的 Agent

目录决定 Agent 能发现哪些 Skill；单个 Skill 是否启用则取决于原生配置支持，目前仅 {{len .Native}} 个 Agent 提供该项设置：

    {{- range .Native}}
  • {{.Name}} {{.Native.File}}
    • {{- end}}
